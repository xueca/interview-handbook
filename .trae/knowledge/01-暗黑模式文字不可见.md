# 暗黑模式文字不可见

> 来源: `specs/fix-ai-chat-dark-text`
> 标签: #CSS #暗黑模式 #AiChat #对比度
> 日期: 2026-06

---

## 问题根因

暗黑模式下 AiChat 页面文字对比度极低，AI 消息内容和标签几乎不可见。

**直接原因**：`dark.css` 覆盖了聊天消息背景色（`.message-content` 背景设为 `#1d1d1d`），但**未覆盖文字颜色**。亮色模式下的文字颜色 `#303133`（深灰）在暗色背景上完全看不清，不满足 WCAG 最低对比度标准。

**深层原因**：新增 UI 组件时，只测试了亮色模式，没有验证暗色模式下的显示效果。CSS 主题切换的本质是"背景色 + 文字色"必须成对覆盖，只覆盖一方必然导致对比度问题。

---

## 解决方案

在 `frontend/src/styles/dark.css` 中为 AiChat 页面所有文字元素补充暗色模式颜色覆盖：

| 元素 | 暗色模式颜色 | 用途 |
|------|-------------|------|
| `.message-content` | `#e5eaf3` | AI 消息正文 |
| `.message-role` | `#a3a6ad` | 角色标签（用户/AI） |
| `.rec-title` | `#a3a6ad` | 推荐问题标题 |
| `.rec-item` | `#e5eaf3` | 推荐问题文本 |
| `.thinking-indicator` | `#a3a6ad` | 思考中指示器 |
| `.message-content pre` | 暗色背景 | 代码块 |

**影响范围**：仅修改 `dark.css` 一个文件，不涉及 JS 逻辑或数据流。

---

## 如何避免再次发生

1. **新增 UI 组件时，必须同时定义亮色和暗色两套样式**。暗色模式不是"后期补"，而是"从一开始就写"。
2. **CSS 变量优先**：用 `var(--text-primary)` 等语义化变量代替硬编码颜色，dark.css 只需覆盖变量值，新组件自动适配。
3. **提交前检查清单**：每新增一个带颜色的 UI 元素，在亮色和暗色模式下各截图一次，确认可读性。
4. **WCAG 对比度基准**：正文文字对比度 ≥ 4.5:1，大号文字 ≥ 3:1。`#e5eaf3` 在 `#1d1d1d` 上对比度约 12:1，远超标准。

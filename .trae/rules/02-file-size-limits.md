# 文件规模约束（不可放宽）

> 版本: v3.0 | 项目: 面试宝典（Interview Handbook）
> 本规则始终生效。任何代码生成、修改、重构操作都必须遵守。

## 硬上限（无例外）

| 文件类型 | 行数上限 | 超标处理 |
|---------|---------|---------|
| .vue 组件 | ≤ 200行 | 抽composable / 子组件 |
| .js 逻辑文件 | ≤ 150行 | 拆工具模块 |
| controller | ≤ 150行 | 拆service/工具函数 |
| 单个函数 | ≤ 30行 | 拆小函数 |
| 函数参数 | ≤ 4个 | 用对象包裹 |

## 裁决规则

当"功能写不完"与"文件超行"冲突时，**听行数限制的**。拆文件的成本是5分钟，重构屎山的成本是5小时。

## 预防手段

- ESLint已配置: `max-lines: 200`, `max-lines-per-function: 30`, `max-params: 4`
- 提交前自动检查

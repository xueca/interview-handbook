## 四、唯一待执行项：Code Guardian MCP Server

### 为什么是唯一

所有其他文档要么已完成、要么正在使用、要么可归档。mcp-ai-coding-workflow-v2.md 中 Code Guardian P0 是唯一方案成熟但尚未落地的功能。

### 当前替代方案

在 Code Guardian 实施前，已有等效能力：
- `/review` Command — 手动触发 5 步审查（ESLint + 文件大小 + 架构合规 + SSE 专项 + 代码质量）
- after-write Hooks — 自动检查文件大小 + .vue 直接 fetch 反模式
- Husky pre-commit — 提交时自动 ESLint 修复

Code Guardian 的价值是将这些能力统一为 MCP Tool，让 AI 在编码中主动调用而非被动等待。

### 实施前提

- echo-server 通路已验证 ✅
- 复用 check-file-size.js + eslint-plugin-architecture ✅
- 方案 v2.x 已多次迭代，六项风险均有缓解措施 ✅

## 一、抖音 GitHub 开源项目宣传排版风格总结

### 1.1 封面设计规范

**尺寸与比例**：
- 封面尺寸：1080x1440px（3:4 竖版），抖音个人主页展示的标准封面比例
- 视频本身：1080x1920px（9:16 竖屏）
- 导出设置：高清导出，码率"推荐"或"更高"

**封面排版结构（技术类视频专用）**：
```
+----------------------------------+
|  [顶部 15%] 留白/账号名          |
|                                  |
|  [中上 1/3] 大字标题（核心关键词）|
|  字号: 48-72pt                   |
|  字体: 思源黑体 Bold              |
|  颜色: 白色 #FFFFFF + 阴影 #333  |
|  背景色块: 高对比色               |
|                                  |
|  [中部 40%] 主视觉区              |
|  产品截图/录屏帧/代码截图         |
|                                  |
|  [底部 20%] 副标题+标签           |
|  字号: 24-32pt                   |
|  "开源免费" "GitHub" 等关键词     |
|                                  |
|  [右下角] 80x80px 统一水印       |
|  透明度 60%                      |
+----------------------------------+
```

**封面文字规则**：
- 核心关键词不超过 8 个字（如"面试刷题神器"、"AI编码不翻车"）
- 关键词加粗 + 高饱和色块衬底（橙红 #FF6B35 或深蓝 #2A5CAA）
- 文字位置固定在中上 1/3 区域，左右留白不小于 15%
- 阴影强度 3，阴影颜色深灰 #333333

**配色体系**：
- 面试宝典系列：主色深蓝 #2A5CAA + 辅色浅灰 #F0F4F8（专业、可信赖）
- Code Guardian 系列：主色翠绿 #2ECC71 + 辅色深灰 #2C3E50（安全、通过）
- 所有封面保持同一色系内微调，3-5 期保持视觉一致性

### 1.2 视频内容结构（技术类爆款公式）

**黄金 3 秒开头**（决定用户是否继续观看）：
- 方式A：痛点提问式 -- "AI 写的代码，你敢直接用吗？"
- 方式B：数字冲击式 -- "6 个检查，让代码合规率从 60% 到 100%"
- 方式C：效果前置式 -- 先展示最终效果（绿色通过画面），再倒叙

**中段 10-40 秒**（核心价值展示）：
- 录屏演示为主，画面速度 1.5x-2x 加速
- 每个功能点展示 2-3 秒，配合字幕说明
- 关键操作加红色/绿色框标注

**结尾 3-5 秒**（行动号召）：
- GitHub 搜索关键词 + "开源免费"
- 箭头指向评论区（引导看置顶评论）

### 1.3 字幕样式规范

**字体与排版**：
- 字体：思源黑体 Bold（中文）/ Montserrat Bold（英文数字）
- 字号：标题 48pt / 副标题 32pt / 正文 24pt
- 位置：居中偏下，距底部 15%
- 背景：半透明黑色条（透明度 60%）或纯色底条
- 单行不超过 15 个字，超过自动换行

**字幕节奏**：
- 每句字幕停留 1.5-3 秒
- 关键数据用黄色/红色高亮
- 功能名称用引号或方括号包裹

### 1.4 BGM 选择策略

- 类型：轻电子/科技感背景音乐
- 音量：20-30%（不盖过字幕信息）
- 推荐：剪映"科技"分类下的免费 BGM
- 节奏：中速偏快（120-130 BPM），配合录屏操作节奏
- 避免：带歌词的歌曲（分散注意力）

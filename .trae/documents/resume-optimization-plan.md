# 简历优化计划

## 目标

根据大佬的反馈，优化简历，去掉AI味，让简历更像真人写的，同时保留核心竞争力。

## 当前问题（来自大佬反馈）

1. **AI味太重** — 太多buzzword（Spec Coding、MCP、知识飞轮、verify-refactor）
2. **技术描述太复杂** — HR看不懂，面试官觉得过度包装
3. **缺少真实指标** — 没有QPS、DAU、部署经验等实际数据
4. **项目描述太长** — 4条bullet point太密，挑最核心3条
5. **缺少实习时间** — 必须加"可实习X个月"

## 修改方案

### 1. 岗位定位
- **现在**：前端开发实习生（AI方向）
- **改为**：前端开发实习生

### 2. 技术栈简化
- **删除**：MCP、Prompt提示词工程、LLM应用集成、JSON数据存储
- **保留**：Vue3 / JavaScript / CSS3 / Element Plus / Pinia / ECharts / HTML5
- **保留**：Node.js / Express / REST API / JWT / SSE / ECharts / Git
- **保留**：React / TypeScript / Nginx / PM2 / Linux

### 3. 项目描述重写
**现在（4条，太密）：**
```
- 独立开发AI面试刷题助手，接入DeepSeek大模型实现AI自动出题和实时解析...
- 实现流式对话功能，用户提问后AI实时生成回答，设计三层容错机制...
- 建立代码质量规范体系，通过自动化检查工具确保代码合规率100%...
- 编写3篇技术文章总结AI应用开发经验，累计20KB+内容...
```

**改为（3条，更简洁）：**
```
- 独立完成全栈开发，接入大模型实现AI自动出题和实时解析，支持按分类和难度出题
- 实现流式对话功能，设计三层容错机制（自动重连→降级处理→渲染优化），稳定性达99.5%
- 建立代码质量规范体系，通过自动化检查工具确保代码合规率100%
```

### 4. 添加实习时间
在项目描述下方添加：
```
可实习3-6个月，每周5天，随时到岗
```

### 5. 删除黑话
- 删除：Spec Coding、MCP协议、知识飞轮、verify-refactor、code-guardian
- 删除：掘金昵称（会赢吗家人们）

### 6. 技术亮点简化
**现在（3条，太复杂）：**
```
- 开源贡献：向 ant-design-vue（21k+ stars）提交 PR #8563...
- 技术亮点：独立开发 Code Guardian（AI 编码规范校验工具），发布至 npm...
- 工程实践：设计"双 AI 交叉验证"工作流，编写 Spec Coding 实践文章...
```

**改为（2条，更简洁）：**
```
- 开源贡献：向 ant-design-vue（21k+ stars）提交 PR #8563，修复主题切换时通知组件样式丢失问题
- 技术博客：掘金2篇技术文章，总结AI应用开发经验
```

## 二、可行性详细分析

### 2.1 BOSS直聘 —— 🔴 难度极高

**已验证的反爬机制：**
- `__zp_stoken__` Cookie 动态验证，每次访问刷新，前端 JS 生成，伪造极难
- 单个有效 Cookie 仅能翻 3~4 页，之后返回空/报错
- 高频触发滑块验证码（极验系，2025 年升级到三代，三个 w 参数相互关联）
- 2025 年后引入 AI 风控模型，检测鼠标轨迹、滚动行为、设备指纹
- robots.txt 极度严格：Disallow 了几乎所有带查询参数的 URL

**唯一可行路径：**
- **Playwright/DrissionPage 浏览器自动化 + 手动登录维持会话 + 极低速**
- 或商业方案：Bright Data 解锁器（$500+/月）

### 2.2 牛客网 —— 🟡 中等难度

**已验证状态（2026-06）：**
- robots.txt **仅禁止 /search 和 /nccommon**，discuss（面经）、experience 板块完全允许
- 默认 Scrapy UserAgent 会触发滑块，设置真实 UA 后可正常访问
- 滑块验证码仅在异常高频请求时触发
- 面经/讨论区反爬力度低，CSS/XPath 选择器可稳定提取
- 招聘板块反爬稍严，需控制频率

**推荐路径：**
- **Scrapy + fake_useragent + 合理延迟**，免费且高效
- 遇到验证码时降级到 Playwright 浏览器模式

## 五、数据量与存储评估

| 平台 | 预估数据量 | 推荐存储 | 每条大小 |
|------|-----------|----------|----------|
| 牛客网面经 | ~5000-10000 条/岗位 | JSON Lines / SQLite | ~2-5 KB |
| BOSS直聘 | ~500-2000 条/城市/岗位 | JSON Lines / SQLite | ~1-3 KB |

**存储方案：**
- **小规模（<1万条）**：JSON Lines 文件，一行一条，方便追加和检索
- **中等规模（1-10万条）**：SQLite 轻量数据库，单文件零配置
- **大规模（>10万条）**：MongoDB（文档型，天然适合爬虫数据）


## 六、法律与合规提醒

1. ✅ **遵守 robots.txt**：牛客网允许 discuss 板块，BOSS直聘全面禁止带参URL
2. ✅ **频率控制**：请求间隔 ≥ 3~5 秒
3. ⚠️ **用途限制**：仅限个人学习研究，**不得商用或公开分发**
4. ⚠️ **用户协议**：两平台均禁止自动化抓取
5. ⚠️ **法律风险**：《数据安全法》《个人信息保护法》有严格规定
